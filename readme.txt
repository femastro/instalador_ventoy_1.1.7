FORMA AUTOMATICA :
==================

ejecutar el archivo .sh de esta manera.

terminal $> bash install.sh

ATENCIÓN_: En el caso de que no se ejecute. crear el usuario Root :

sudo passwd root

ó 

terminal $> python3 install.py
